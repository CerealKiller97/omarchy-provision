# Architecture

Omarchy Provision is a static [SvelteKit](https://svelte.dev/docs/kit) site built with
`adapter-static`. There is no backend: the page builds the config in the browser, keeps it in
`localStorage`, and exports YAML. Omarchy's own data is baked in at build time by the
[sync workflows](omarchy-sync.md).

## Where things live

| File | Purpose |
| --- | --- |
| `src/routes/+page.svelte` | The form and live YAML preview |
| `src/lib/options.ts` | All predefined choices (browsers, terminals, editors, agents, themes, preinstalls, services, dev envs). Values match the `omarchy:args` headers of the `omarchy-*` scripts |
| `src/lib/config.ts` | Config type, field validators, cross-field checks (`checkConfig`) and the YAML generator (`toYaml`) |
| `src/lib/omarchy.json` | Latest Omarchy release, package lists, built-in theme palettes and install menus. Generated by `pnpm sync:omarchy`; don't edit by hand |
| `src/lib/community-themes.json` | Community themes from [omarchy.org/themes](https://omarchy.org/themes). Generated by `pnpm sync:themes`; don't edit by hand |
| `static/themes/{builtin,community}/` | Self-hosted theme preview thumbnails, written by the sync scripts. Don't edit by hand |
| `static/apply.sh` | The script that applies an exported config ([docs](applying.md)) |
| `src/lib/icon-catalog.ts` | Quick-pick launcher icons (dashboard-icons PNGs on jsDelivr) and the URL/command matchers that suggest them |
| `src/lib/analytics.ts` | The Umami export event (predefined choices only) |
| `src/lib/site.ts` | Site copy, author, repo link, analytics and security contact |
| `src/lib/components/` | `OptionSelect`, `CheckGroup`, `TagInput`, theme pickers and friends; `ui/` is shadcn-svelte |
| `src/routes/{sitemap.xml,robots.txt,.well-known/security.txt}/+server.ts` | Generated at build time from `SITE_URL` and `SITE.securityContact` |
| `scripts/sync-omarchy.mjs`, `scripts/sync-community-themes.mjs` | The sync scripts ([docs](omarchy-sync.md)) |
| `scripts/brand/` | Favicon, social card and README banner sources ([docs](brand-assets.md)) |

## Notes

- **App logos** in the form come from [Simple Icons](https://simpleicons.org) via the `icon` field in
  `options.ts`.
- **Theme previews are self-hosted** because the site's Content Security Policy only allows
  same-origin images. Each filename ends in the upstream file's blob sha, so a preview is only
  re-encoded when upstream changes it.
- **`security.txt`** gets an `Expires` date 360 days out on every build, so each deploy renews it.
